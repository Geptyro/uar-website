---
title: The items page is gone — entities covers it
type: improvement
area: wiki
---
Every item is an entity, so the separate items list only repeated what
**Entities** already shows. It has been removed: filter Entities by the item
categories for the list, and open an item to get its effects, charges, who can
use it and what it conflicts with. Item links on class pages now go straight
to that page.
