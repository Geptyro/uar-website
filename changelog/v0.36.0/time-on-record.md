---
title: Time on record on every profile, counted per player
type: feature
area: players
---
A profile's infobox now shows how long that player has spent in the games on
record — beside "Games played", with the number of recorded games it covers,
since the map's own career count runs far ahead of what anyone has uploaded.
The [players board](/players) has the same figure as a sortable "Time on
record" column, in place of the three per-track XP columns (Enlisted, Warrant
Officer, Commissioned Officer) — those live on each profile, and Career XP
already sums them here. On the profile, "Classes played" shows the time on
each class beside its game count.

It is each player's *own* time, not the game's: a replay records the moment
every player left, so someone who quit at minute two of a ninety-minute game
is written down for two minutes. That same rule now feeds the per-class
playtime boards and the "played with" lists, which used to credit every
player in a game with the whole game — about 7% phantom time across long
lobbies, most of it landing on the few who left early.

The map's "Avg game" figure is unchanged and now carries a note about what it
actually is: the map only updates it after a loss.
