---
title: Search engines can now tell which profiles have actually changed
type: improvement
area: site
impact: minor
---
The sitemap now says when each player profile and clan page last moved, so a
search engine re-reads the ones that have seen a game rather than all 850 of
them — which keeps the crawling off the database.

Five profiles were missing from the sitemap entirely: it listed players by
in-game name, so anyone without one, or sharing one with another player, never
got listed.
