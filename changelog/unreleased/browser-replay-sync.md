---
title: Upload your replays from the browser, without installing anything
type: feature
area: replays
impact: major
---
Not everyone wants to run a downloaded program, and you no longer have to. On
the [replays page](/replays) you can point this site straight at your
StarCraft II replay folder and it uploads the Undead Assault Reborn games it
finds — no install, no account beyond the one you already have.

Everything else in that folder is ignored, and that is decided **on your
machine**: each file is opened locally and only sent if it is a UAR game. Your
ladder matches and other arcade games are never uploaded, and the site never
learns where the folder is — only that you allowed it to read one. You can take
that back at any time in your browser's site settings.

Syncing again later is quick: files it has already dealt with are remembered,
so a second run only looks at what is new.

Two things worth knowing. It needs Chrome, Edge or another Chromium browser on
desktop — Firefox and Safari have no way to hand a folder to a web page. And it
only runs while the page is open, so if you want your replays to go up while
you play, without thinking about it, the companion app is still the one that
does that.
