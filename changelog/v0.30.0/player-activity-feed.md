---
title: See what each game earned you
type: feature
area: players
impact: major
---
The new **Activity** tab on a profile lists the games that gave something —
a medal, a camouflage, a decal, a Skill Identifier, a piece of vehicle gear, a
new rank, or a prestige — with the game it came from and when it was played.

Two things worth knowing about how it reads the record:

- The map writes your save file at the **start** of a game, so what a game gave
  you only shows up in the next one. The newest game on a profile never lists
  anything until another replay is uploaded.
- If you played games that were never uploaded, a reward cannot be pinned to a
  single one. Those are marked "somewhere in N games" with a hollow marker, and
  the missing run is drawn on the timeline rather than quietly closed up.
