---
title: Search opens on F, and Ctrl+F is the browser's again
type: improvement
area: site
---
Pressing F anywhere on the site opens the search. It used to be Ctrl+F,
which got in the way every time you wanted the browser's own find on the
page in front of you. That key now does what it does everywhere else.

Ctrl+K and / still open the search too. None of the plain keys fire while
you are typing in a field, so an F in a filter box is just an F.
