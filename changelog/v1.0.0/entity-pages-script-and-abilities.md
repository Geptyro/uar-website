---
title: Entity pages list their triggers and abilities
type: feature
area: wiki
---
Every entity page now has an "In the script" table: each trigger of the map that spawns, listens to, removes or mentions the unit, with what makes the trigger fire. Names link to the mission flow graph when the trigger is part of it. Units with documented abilities (the MULE's digging protocol, the drones, the NPC heroes) show them as a command card, the same one the class pages use.
