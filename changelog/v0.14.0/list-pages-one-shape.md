---
title: Entities and items read like the players table
type: improvement
area: wiki
---
The entity and item lists now use the same shape as **Players**: the search,
the filters and the column header stay put while only the rows move, the table
fills the window down to the bottom edge and runs the full width of the page,
and every row is numbered in the order you sorted it.

Item columns can be sorted too — by name, by type or by charges — and the
whole table keeps its filters while you do.
