---
title: Every class page has its MOS code, role and description back
type: fix
area: wiki
---
Nine classes — the Assault Engineer, Combat Engineer, Combat Medic, Phoenix
Medic, Flamethrower, Sniper, Prototype, Cyborg and the APC — were showing no
description at all, and several more had no MOS code or role. The site was
looking up the wrong text: in the game data those blurbs are filed under the MOS
code, not the unit name.

Every class now reads its description from the hero-selection screen, the same
words you see when you pick it. The MOS/Role banner and the rank requirements
that used to be repeated inside the description are gone from it — they were
already on the page, right next to the rank icons.
