The [Rjx-73](/mos/Rjx73/gear) showed no weapons, because the map swaps its gun in when you learn a module. Its minigun, flamecannon and grenade launcher are now listed, each with the module that gives it. The Grenade Launcher tree's upgrades now name the launcher. Before, they named Punisher Rockets, which fires the same grenades.
